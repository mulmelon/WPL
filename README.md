**A free, open-source, copyleft software license with a little watermelon humor.**

The Watermelon Public License (WPL) is a software license created by **MulMelon** in 2026.

Its philosophy is simple:

**Use it. Improve it. Share it. Give credit. Share your changes.**

## What Can You Do?

-  Use the software for personal or commercial purposes.
-  Modify, copy, and redistribute the software.
-  Sell software licensed under WPL.
-  Make private modifications without publishing them.
-  Keep the original copyright notice and license.
-  Release distributed derivative works under WPL and provide their source code.

## How to Use WPL

1. Add a `LICENSE` file containing the full Watermelon Public License.
2. Include your copyright notice.
3. State that your project is licensed under WPL Version 1.0.
